Upsert records via API (PATCH if id present & exists; otherwise POST)

Description

Upsert records via API (PATCH if id present & exists; otherwise POST)

Usage

upsert(
  url,
  data,
  headers = list(),
  id_col = "id",
  style = c("auto", "plain", "feature"),
  chunk_size = 200L,
  base_url = "https://cramerdb.com/api/",
  dry_run = FALSE,
  staging = FALSE
)

Arguments

url

Endpoint - full URL or relative path (e.g., "seine/event/" or "https://cramerdb.com/api/seine/event/")

data

data.frame or sf tibble

headers

named list of HTTP headers

id_col

primary key col (default "id")

style

"auto", "plain", or "feature"

chunk_size

number of rows per request batch

base_url

Character. Base API URL (default: "https://cramerdb.com/api/")

dry_run

Logical. If TRUE, show what would be sent without actually sending. Useful for validation.

staging

Logical. If TRUE, routes requests to the staging server.
