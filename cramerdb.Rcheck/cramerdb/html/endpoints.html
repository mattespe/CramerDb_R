endpoints {cramerdb}R Documentation

List available API endpoints

Description

Navigate the CramerDB API tree structure by listing available endpoints. Use whoami() to check authentication status.

Usage

endpoints(
  path = NULL,
  base_url = "https://cramerdb.com/api/",
  headers = list(),
  staging = FALSE
)

Arguments

path

Character. Optional API path segment (e.g., "seine", "biology"). If NULL or missing, lists the root API endpoints.

base_url

Character. Base API URL (default: "https://cramerdb.com/api/")

headers

Named list of HTTP headers (e.g., list(Authorization = "Token xxx"))

staging

Logical. If TRUE, routes requests to the staging server.

Value

Invisibly returns the parsed JSON response; prints formatted output

Examples

## Not run: 
# List top-level endpoints
endpoints()

# List endpoints for a specific section
endpoints("seine")
endpoints("biology")

# Equivalent to:
endpoints("biology/some-sub-path")

## End(Not run)
