browse_endpoints {cramerdb}R Documentation

Browse API endpoints interactively

Description

Uses interactive filtering (if gum is available) to browse and explore API endpoints. Falls back to listing all endpoints if gum is not available.

Usage

browse_endpoints(
  base_url = "https://cramerdb.com/api/",
  path = NULL,
  staging = FALSE
)

Arguments

base_url

Character. Base API URL (default: "https://cramerdb.com/api/")

path

Character. Optional starting path (e.g., "seine")

staging

Logical. If TRUE, routes requests to the staging server.

Value

Selected endpoint URL or NULL if cancelled

Examples

## Not run: 
# Interactive browsing (requires gum)
browse_endpoints()

# Start from a specific path
browse_endpoints(path = "seine")

## End(Not run)
