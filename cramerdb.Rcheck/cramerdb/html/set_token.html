set_token {cramerdb}R Documentation

Set the CramerDB API token for this R session

Description

Stores the token securely in your system's credential store (Keychain on macOS, Credential Manager on Windows, Secret Service on Linux). The token persists across R sessions and is retrieved automatically when needed.

Usage

set_token(token, persist = TRUE)

Arguments

token

Character scalar token value (no "Token " prefix needed).

persist

Logical. If TRUE (default), store in system keyring for persistence across sessions. If FALSE, store only in R options for current session.

Details

If the keyring package is not available, falls back to storing in R options for the current session only.

Examples

## Not run: 
# Store token securely (persists across sessions)
set_token("abcd1234...")

# Session-only storage
set_token("abcd1234...", persist = FALSE)

## End(Not run)
