get_token {cramerdb}R Documentation

Get the currently configured CramerDB API token

Description

Retrieves the token from (in order of priority):

  1. R options (current session)

  2. System keyring (if available)

  3. CRAMERDB_TOKEN environment variable

Usage

get_token(error_if_missing = FALSE)

Arguments

error_if_missing

Logical. If TRUE, error when no token is found.

Value

The token string, or NULL if not set (and error_if_missing = FALSE).

Examples

## Not run: 
get_token()

## End(Not run)
