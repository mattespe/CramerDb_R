fetch {cramerdb}R Documentation

Fetch any Cramer API endpoint into a tibble

Description

fetch() follows pagination automatically and normalizes both plain JSON lists and GeoJSON FeatureCollections into a plain tibble.

Usage

fetch(
  url,
  headers = list(),
  base_url = "https://cramerdb.com/api/",
  staging = FALSE,
  query = list()
)

Arguments

url

Character. Full URL or relative path (e.g., "tagging/event/"). Relative paths are prepended with base_url.

headers

Named list of HTTP headers (e.g., list(Authorization = "Token xxx")).

base_url

Character. Base API URL (default: "https://cramerdb.com/api/")

staging

Logical. If TRUE, routes requests to the staging server.

query

Named list of query parameters appended to the URL.

Value

A tibble.
